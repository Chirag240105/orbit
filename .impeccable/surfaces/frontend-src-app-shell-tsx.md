# App shell and screens (Operate)

Scope: the whole ORBIT web app shell (sidebar, header, sign-in) and its screens, with the Visual Learning Studio as the lead surface. Mode: Operate. Audience: students learning how systems work, in long laptop sessions. Constraints: keep every route, control, and behavior; the 3D studio's look is a brand commitment and stays.

## Direction contract

THESIS: ORBIT is a learner's star atlas: systems are constellations you explore. It refuses the category default of a grey dev-tool with one violet accent.

OWN-WORLD: Deep indigo-navy night ground with tinted surfaces, star-white ink, comet amber as the single action/selection accent, nebula violet and teal for data and secondary states. Fine hairline rings and borders like chart graticules. Geometric display face for titles and the wordmark, a clean humanist UI sans for text, mono only for code and data.

STORY: The learner sees where they are, searches a system, explores it in 3D, and saves what they learn, without hunting for anything.

FIRST VIEWPORT: Left rail with the ORBIT orbit-mark and wordmark, navigation with the active item marked by an orbit ring; header with workspace and model status; Visual Learning page with a large title, the system search as the primary action, suggestion chips, then the 3D stage and the explanation column.

FORM: Star atlas, candidate 4 of 7 on the ordered list; seed:1c828f315f5d5e37. Signature move: the orbit ring (a ring with a node on it) marks active navigation, the selected part, and the logo. Raises: color encodes kind consistently across 3D, list, and panel, never labeled twice (from the catalog-sleeve challenger); a real type scale from caption to display (from the metro challenger).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
